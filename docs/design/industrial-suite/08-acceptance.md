# 验收矩阵与性能口径

版本：0.1.0-draft  |  日期：2026-09-23  |  状态：拟议设计

目标：在 `a1112/UniVision` 单仓库内作为可选扩展落地。本文不代表已实现或已验收。

## 27  验收矩阵 A：共享与传输

| ID | 测试场景 | 通过条件 |
| --- | --- | --- |
| C01 | Core-only 配置/安装 | 默认构建、已知消费者不受扩展影响 |
| C02 | 版本/Schema 不兼容 | 未知 major 拒绝，不猜测转换 |
| C03 | uint64/纳秒往返 | JSON 字符串无精度丢失 |
| C04 | 布局长度/步长错误 | 消费前拒绝，无越界分配 |
| C05 | 非法路径/符号链接 | 制品不能逃出工作区 |
| C06 | 时钟未映射或跳变 | 不报告伪同步/伪单向延迟 |
| C07 | 原始深度与单位 | 不因预览编码改变原始量 |
| C08 | 提交各阶段崩溃 | 有效前缀可解释，缺失不伪装完整 |
| S01 | 拆包/粘包/分片 | 帧边界正确、哈希一致 |
| S02 | 重复键同/不同哈希 | 同哈希幂等，不同哈希拒绝冲突 |
| S03 | received 与 durable | 未持久化不得宣告 durable |
| S04 | 慢预览/快必需消费者 | 队列隔离，预算有界 |
| S05 | 缓存内/外断网恢复 | 可恢复区间补传，超范围出 GAP |
| S06 | 解压炸弹/超大长度 | 预检拒绝，内存不上升到对端指定值 |
| S07 | 证书过期/身份未授权 | 拒绝连接或订阅，不退明文 |
| S08 | 4 路峰值/波动输入 | 报告实际吞吐/延迟/资源/缺口，无伪达标 |
| S09 | 发送方/接收方重启 | 仅按已提交账本恢复，不复用旧认证 |
| S10 | 停止/排空超时 | 未交付清单准确，无后台悬挂租约 |

本矩阵是计划，尚未运行产品测试。S08 必须绑定现场可用硬件和真实代表性数据；本包的小型合成样例验证不能替代四路高吞吐测试。

## 28  验收矩阵 B：回放、测量与流程

| ID | 测试场景 | 通过条件 |
| --- | --- | --- |
| R01 | 录制→读取→对比 | 身份、格式、时间、载荷一致 |
| R02 | 随机 seek/并发预览 | 旧 generation 不覆盖新视图 |
| R03 | 尾段损坏/索引缺失 | 恢复标记准确，不伪造缺失帧 |
| R04 | 时钟/坐标/输入不同 | 不可比条件被明确拦截 |
| R05 | 同输入两版算法 | 差异可定位到帧、参数与环境 |
| R06 | 重跑/评审 | 原始输入哈希不变 |
| M01 | 理想/噪声合成圆 | 满足声明的数学容差，标注 synthetic |
| M02 | raw 码/缺标定 | 禁止用于毫米判定 |
| M03 | 退化弧/异常点/无收敛 | 返回 invalid，不沿用上一帧 |
| M04 | 预算/相关性缺失 | 不能宣告测量能力通过 |
| M05 | 边界误差/护栏 | pass/fail/indeterminate 规则可复算 |
| M06 | 独立参考件数据 | 输入/条件/证据完整，不冒充合成数据 |
| F01 | 循环/类型/单位错 | 运行前定位错误 |
| F02 | 缺节点/版本/模型 | 不旁路、不自动下载 |
| F03 | 运行中编辑 | 旧 run 不变，新 revision 单独执行 |
| F04 | 取消/Worker 崩溃 | 输出与状态一致，必需 Sink 未提交不成功 |
| F05 | CLI 与 UI | 相同冻结图使用同一执行语义 |
| F06 | 缓存/状态节点 | 按确定性等级验证，无旧结果误复用 |
| F07 | 真实设备/任意脚本节点 | 离线首版在引擎层拒绝执行 |
| F08 | 无效测量流入判定 | 不得转换成默认 pass |

证据需记录 commit、build、test case、input hash、expected/observed、日志/制品引用和验证人。总体运行通过不代表每一项实机或测量认证通过。

## 29  性能目标、部署与发布门槛

### 先定义计量口径

| 指标 | 必须注明 |
| --- | --- |
| 数据吞吐 | 原始/编码/payload/wire 口径、总路数与每路分布；平均与峰值 |
| 延迟 | 首行/末行、接纳/接收/落盘/处理边界；P50/P95/P99 与样本数 |
| 队列/内存 | 预算内 OwnedFrame、重组、编码、磁盘缓冲分别统计；进程 RSS 另报 |
| 完整性 | accepted、received、durable、processed、gap、rejected 数量可核对 |
| 回放 | 数据集/索引大小、磁盘、seek 位置分布和预览分辨率 |
| 测量 | 数值容差、重复条件、参考件与不确定度，不用 FPS 替代精度 |

### 发布分层

L0 文档/Schema 样例校验；L1 单元/合成集成；L2 锁定平台上的实机运行与安装；L3 指定厂商设备、指定数据和条件验收；L4 生产系统集成与现场批准。只能报告已取得的层级，不能跨级授予 GO。

基础 CI 建议 Windows/Linux 的 Core-only 与扩展 headless；GUI 与 macOS 为单独候选，受当前 Core/SDK 实际能力约束。未验证平台标为 not-tested，不因候选 UI 框架支持就写“全平台已支持”。

### 包与退出条件

扩展包包含精确依赖清单、许可证、配置样例、协议/Schema 版本和校验信息；厂商 SDK 与模型按许可单独准备。工作区数据与安装目录分离，升级前检查版本并保留恢复路径。

通过模拟断网、资源耗尽、进程崩溃和数据损坏验证清理与恢复。真实设备写入不属于首版能力，后续不得仅修改配置就把离线包变成现场控制软件。

> 没有测试记录就保留 not-tested；没有标定/预算就保留未验证；没有完整制品就保留 partial。状态真实比报告全绿更重要。
