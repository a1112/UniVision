# UniMeasure 测量验证设计

版本：0.1.0-draft  |  日期：2026-09-23  |  状态：拟议设计

目标：在 `a1112/UniVision` 单仓库内作为可选扩展落地。本文不代表已实现或已验收。

## 17  UniMeasure：从一个可验证任务开始

### 首版被测量

首版选择“离线、已知坐标意义的二维截面圆拟合直径验证”。输入为 x/z 截面点、有效掩码、单位、坐标系和标定引用；输出直径、圆心、拟合残差、有效覆盖、不确定度及方法限定。

合成毫米坐标可以测试数学流程，但必须标记 synthetic。真实 raw-device-code 若没有有效转换与标定证据，不得输出可用于判定的毫米直径；只能显示原始量或 CALIBRATION_INVALID。

| 纳入首版 | 不纳入首版 |
| --- | --- |
| 导入合成/授权截面数据 | 自动配置或写入厂商标定 |
| ROI、点有效性与异常点规则 | 同时实现宽度、厚度、平面度等全部量 |
| 圆模型拟合及方法诊断 | 自动将局部圆拟合等同真实三维外径 |
| 参考值、重复测量与误差评估 | 仅靠标称相机分辨率声称达到 ±0.03 mm |
| 标定版本和可追溯验证报告 | 以拟合残差代替系统测量不确定度 |

### 拟合方法草案

```text
minimize Σ wi × (sqrt((xi-cx)^2+(zi-cz)^2) - r)^2
reported_diameter = 2r
```

先用固定版本的初始化器，再做有终止条件的几何最小二乘；鲁棒权重规则、阈值、迭代上限与种子进入 MethodProfile。法向、截面倾斜、覆盖弧度和椭圆偏离要作为有效性检查。

最低点数/覆盖角阈值由基准集确定；例如 30 点/120° 仅可作开发探针，不是通用精度保证。拟合不收敛、有效点不足或覆盖退化时，返回无效结果而不是沿用上次直径。

## 18  UniMeasure：标定与不确定度

### CalibrationProfile 生命周期

draft → reviewed → approved → superseded/revoked。每一版冻结设备身份、模式、ROI、分辨率、坐标定义、转换、参考件证据、环境范围、日期与审批记录。数据始终引用具体版本，不使用可变“latest”。

更换设备、ROI/采样模式、坐标变换或影响比例的参数后，旧标定的适用性必须重新检查。应用层只选择已批准配置，首版不向真实设备下发标定写入。

### 什么才是测量证据

可追溯性需要包含不确定度的连续校准链；拥有校准证书也不自动保证某个现场用途适用。[S7] 验证集应与拟合/调参集分离，并覆盖尺寸、位置、姿态及环境变化。

| 预算分量（示例） | 评估要点 |
| --- | --- |
| 参考件 | 证书不确定度与适用条件；不要重复计入同一项 |
| 重复性 | 单次结果用单次离散性；只有独立重复且报告均值时才用 s/√n |
| 比例/变换 | 标定参数协方差、拟合模型和坐标映射 |
| 采样/量化 | 像素或码值到长度的传播、无效点和采样位置 |
| 姿态/环境 | 截面倾斜、温度、表面/曝光等方法相关影响 |

```text
uc² = J Σ Jᵀ   （一般情形，包含相关项）
U = k × uc      （注明覆盖因子与解释条件）
```

Type A/Type B 是评估方式，不是“随机/系统误差”的简单别名；相关分量不能直接无条件平方和。k=2 也不能无条件解释为恰好 95% 覆盖。[S7]

> 未完成预算时允许输出探索性数值，但状态必须是 uncertainty-not-evaluated，禁止显示测量能力已达标。

## 19  UniMeasure：结果与判定分层

### 先区分三件事

算法算出了数值、测量结果具备有效条件、结果满足某项限值，是三个不同层次。运行 succeeded 不等于测量 valid，更不等于工件 pass。

| 结果字段 | 要求 |
| --- | --- |
| measurand / method | 截面拟合直径及方法版本；方法定义不省略 |
| value / unit / coordinate_frame | 值、单位和坐标意义；无效时禁止沿用历史数值 |
| input_refs / calibration_ref | 精确输入与标定版本、哈希 |
| fit_diagnostics | 点数、覆盖、残差、收敛与排除比例 |
| uncertainty | uc、U、k、预算引用及其适用对象 |
| validity / decision | valid / invalid / synthetic；pass / fail / indeterminate / not-evaluated |
| decision_rule | 规则版本、限值、guard band 与审批依据 |

### 示例：验证误差限，不是宣布项目精度

仅作计算示例：将允许误差设为 T=0.03 mm，e=Dmeasured−Dreference；Ue 是误差 e 的扩展不确定度，需包含参考值及相关性。建议采用保守护栏：

```text
|e| + Ue ≤ T       → pass
|e| - Ue > T       → fail
其余                → indeterminate
```

若 |e|=0.012、Ue=0.008 mm，则 0.020≤0.030，按该规则通过；若 |e|=0.025、Ue=0.010，则不确定；若 |e|=0.050、Ue=0.008，则失败。这些是自建示例，不能充当实测证据。

工件尺寸公差的 LSL/USL 判定应另定义规则，不能套用误差限公式。合成样例一律 not-evaluated（生产意义）；可另显示数学回归测试通过。

## 20  UniMeasure：界面与验证矩阵

| 区域 | 操作与防误导 |
| --- | --- |
| 中央测量画布 | 显示截面、有效/排除点、拟合圆和 ROI；原始点不被覆盖 |
| 右侧方法面板 | 标定、单位、权重、阈值、参考值、环境与算法版本 |
| 结果卡 | 数值、U/k、有效性和判定分开显示；无效值不显示绿色 |
| 重复实验表 | 逐次结果、平均/离散性、位置/姿态/条件、参考件 |
| 证据页 | 原始输入、配置、证书引用、独立验证集与审批；报告可复算 |

### 四层验证

数学验证：理想圆、固定种子噪声、尺度变化与坐标变换；检查数值容差，不做物理精度声明。数据验证：错误单位、缺标定、退化弧段、异常点、缺少掩码和过期条件必须拒绝。

独立参考验证：使用授权参考件数据，跨重复、位置和条件评估误差及不确定度；不能只挑最好的截面。部署验证：在锁定环境/算法版本下复算，并证明结果与报告的输入摘要一致。

### 报告要求

报告同时写被测量定义、参考值、方法、适用条件、数据排除规则、结果、预算、判定规则与未覆盖范围；不给出“全场景保证 ±0.03 mm”之类超出数据的结论。

> 首个可交付版本的验收目标是“可解释、可追溯、能拒绝无效输入”，不是某个未经确认的毫米数字。

后续扩展到二维边缘距离、轮廓厚度、平面度等任务时，分别新增 MethodProfile、输入类型和验证集。不要把所有测量压成一个不分单位的 measure() 黑箱。
