## 单个 PR 最低材料

变更边界、依赖影响、正反例、可复建命令、结果原始制品、兼容/回滚说明、尚未覆盖的实机条件。默认配置不能静默启用联网或真实设备动作。

## 不允许提前合并的结论

尚无代表性数据时不承诺 JPEG 压缩比；没有目标机实测不承诺 10G 满速；合成圆算对不说明测量精度通过；CI 通过不说明厂商认证或生产验收完成。
